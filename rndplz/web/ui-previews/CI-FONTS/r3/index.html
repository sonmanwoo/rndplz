H5-B · 먼저 볼 중간안

12°는 이탤릭 같은 방향성을 분명하게 주는 제안입니다. 선택한 C의 차분한 워드마크와 부드러운 전자 모션에 맞추는 출발점으로 추천합니다.

제작 방식과 비교 조건

이번 안은 Space Grotesk 정식 이탤릭 파일이 아니라, H5의 같은 글자 형태를 화면에서 기울인 오블리크(oblique) 시안입니다. 세리프를 추가하거나 글꼴 파일을 변형하지 않았습니다. 기울기는 H에만 적용하고 원·전자 궤도·워드마크에는 적용하지 않습니다.

C는 고운바탕 700 + Libre Baskerville 400, H는 Space Grotesk 500을 유지합니다. 같은 서버의 기존 폰트 파일을 그대로 사용하며 원본 라이선스를 함께 제공합니다.
