H1 · C의 영문과 연결하기

워드마크의 Libre Baskerville과 심볼의 H를 같은 계열로 묶는 안입니다. 기존 H의 기울기와 선택한 부드러운 모션을 함께 이어가려면 먼저 볼 후보입니다.

글꼴 출처와 비교 조건

C는 Gowun Batang 700 + Libre Baskerville 400으로 고정했습니다. H1–H5는 실제 폰트 파일을 함께 제공하며 가짜 굵기나 기울기를 만들지 않습니다. Bodoni Moda의 광학 크기는 24로 고정했습니다.

이 페이지는 독립 비교 시안입니다. C·02 선택을 비교 기준으로 반영했으며 새 H의 제품 적용은 미완입니다. 실제 기기별 화면·재생 품질 검증은 미완으로 남아 있습니다. 움직임은 브랜드 시연이며 실제 수소문·발송·응답 상태를 표시하지 않습니다.
