글꼴과 출처

한글 ‘수소문’과 영문 ‘Susomun / SUSOMUN’을 위한 CI 시안입니다. 영문 표기는 비교용이며 공식 영문명 확정과는 별개입니다. 본문 전체에 쓸 글꼴을 선정한 것은 아닙니다.

아래 글꼴은 SIL Open Font License 1.1로 제공됩니다. 각 라이선스 원문을 함께 제공합니다. Google Fonts 공식 text API의 CI 문구 부분집합 파일을 그대로 사용하며 로컬에서 글꼴을 변형하지 않았습니다. 페이지를 열 때 외부 글꼴 서버로 요청하지 않습니다. 본문 글자는 기기의 기본 글꼴로 표시됩니다.
