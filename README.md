# 수소문 · Research, together

질문을 구체화하고, 논문·경력 기록을 근거로 연결할 사람을 찾는 해커톤 서비스입니다.
이 저장소는 배포용 현재 소스 스냅샷입니다. 개발 PC의 대화·첨부·키·과거 Git 이력은 포함하지 않습니다.

## 실행
Python 3.10 이상에서 `pip install -r requirements.txt` 후 Linux에서는
`gunicorn -c gunicorn.conf.py rndplz.public_web:application`을 실행합니다.
Render에서는 이 저장소를 연결한 다음 `render.yaml` Blueprint로 배포할 수 있습니다.

## 공개 범위와 기능
기본 공개 자료는 공개 논문 기반 프로필입니다. 개인 경력은 공개 승인이 있는 배포에만 포함합니다.
방문자별 대화·첨부·시연 제안은 분리됩니다. 제안은 실제 외부인에게 발송되지 않습니다.
API 연결 전에는 “AI 미연결”을 표시하고 기록 탐색 안내 및 근거 검색을 제공합니다.
외부 OpenAI·Claude 모델을 연결하려면 서버에 OPENAI_API_KEY + RNDPLZ_OPENAI_MODEL 또는
ANTHROPIC_API_KEY + RNDPLZ_CLAUDE_MODEL을 설정합니다. 사용할 수 있는 모델은 운영 설정에 따라 달라집니다.

## 검증과 운영
`python -m unittest rndplz.verify_public` / `node rndplz/verify_sphere.cjs`
공개 입구는 WSGI이며 로컬 시연 서버를 인터넷에 직접 노출하지 않습니다.
무료 Render의 파일은 재시작 시 사라질 수 있습니다. 장기 운영에는 별도 영속 저장소가 필요합니다.

사진·출처·AI 생성 일러스트의 구분은 각 카드에서 확인할 수 있습니다.

## 해결하려는 문제

연구자는 기술 문제를 설명한 뒤 관련 경험자를 찾는 과정에서 같은 조건을 반복하고,
추천된 사람의 경험이 어떤 자료로 뒷받침되는지 확인하기 어렵습니다.
수소문은 대화의 목표와 조건을 보이는 의뢰서에 정리하고,
사용자가 명시적으로 수소문할 때 사람과 논문·경력 근거를 연결하는 서비스를 개발하고 있습니다.

## 데모와 확인 순서

[수소문 HTTPS 데모](https://rndplz.onrender.com/)에서 공개 자료의 연구맵·인물·근거 연결을 확인할 수 있습니다.
대화 모델과 서버 설정이 준비된 환경에서는 새 대화를 열고 다음 합성 예시를 사용합니다.

1. “화학공정의 모델 예측 제어(MPC)를 연구한 사람을 찾고 있어요.”라고 입력합니다.
2. “직접 구현을 맡기려는 것은 아니고, 입력 제약과 모델 불확실성에 대한 자문을 구하고 싶어요.”라고 덧붙입니다. 의뢰서에 필요한 도움과 맡기지 않을 일이 함께 남는지 확인합니다.
3. 의뢰서를 검토하고 수소문 버튼을 명시적으로 누릅니다.
4. 결과가 표시되면 인물 카드와 상세의 근거·한계를 비교합니다. 후보가 없으면 자료 내 미발견인지, 필수 조건 미입증인지, 모델 장애인지 구분해 표시하는지 확인합니다.
5. 연구맵의 팀 연결과 필터를 열고 닫아 원래 인물과 근거로 돌아오는지 확인합니다.

이 순서는 확인 절차이며 전체 통과를 주장하는 결과표가 아닙니다.
운영 사용자의 기존 대화에 시험 내용을 넣지 않습니다.

## 현재 확인 범위와 남은 한계

아래는 2026-09-21 확인 시점의 상태입니다.

- 연구맵과 공개 인물·근거 연결의 기존 확인 결과는 유지합니다. 응답 중 다음 질문 작성, 수소문 CI 교체와 서비스명 통일을 공개 서비스에 반영했습니다. 입력 보존과 표시 상태는 PC·모바일 합성 검증으로 확인했으며, 배포 파일의 일치도 확인했습니다. 실제 모델의 추천 품질 검증과는 별개입니다.
- 최근 별도 Gemini 시험에서는 상담 응답을 받았지만 후속 수소문 단계가 HTTP 503으로 종료됐습니다. 실제 사용자 두 턴에서 근거 있는 추천 카드·상세까지 이어지는 흐름은 아직 통과하지 못했으며, 공개 서비스에 Gemini를 반영한 것으로 표시하지 않습니다.
- TCB 연구목표를 필수 과거경력으로 잘못 해석하는 경우와 결과의 인물 식별자 오류는 개선·재검증 중입니다. 관련 자료의 발견과 요청 조건의 입증을 같은 것으로 보지 않습니다.
- 실제 Google 로그인·영속 저장·운영 크레딧 확인과 새 Chrome 시크릿 창의 전체 서비스 최종 검증은 별도 미완입니다. 합성 인증·테스트 원장 성공을 실제 운영 완료로 표시하지 않습니다.
- 실제 외부 연락, 대회 제출, 사람의 업무 성과 평가는 수행 완료로 주장하지 않습니다.

모델 장애나 미확인 항목을 추천 실패·성공과 구분하며, 이 문서 보완만으로 제출 준비와 전체 서비스 검증이 끝났다고 보지 않습니다.
