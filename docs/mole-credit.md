# mole 참여 포인트 v1

mole은 현금 가치가 없는 참여 포인트입니다. 계정의 최초 잔액은 0이며, 내 메뉴에서 잔액과 적립·정정 내역을 확인합니다. 검색 순위, 평판, 실제 역량이나 협업 성과를 뜻하지 않습니다.

## 첫 경험 등록

로그인한 계정이 경험의 **내용과 본인 역할**을 입력하거나 자료에서 검토·채택하고 실제로 새 변경을 저장하면 계정당 한 번 **+1 mole**을 적립합니다. 글 길이, 학위, 증빙 파일이나 공개 설정을 추가로 요구하지 않습니다. 이 조건은 작성 참여를 확인하는 것으로, 경력의 진위를 검증하는 절차가 아닙니다.

조회, 로그인, 자료 업로드만 수행한 경우, 같은 값의 반복 저장, 재시도, 방문자·시연 기록에는 적립하지 않습니다. 기존 자료에 소급 지급하지 않습니다. 과거에 적립받았다면 경력·프로필·요청 ID나 정책 버전이 바뀌어도 다시 적립되지 않습니다.

경력을 수정·삭제하거나 자료 연결을 해제해도 정상 적립은 차감하지 않습니다. 첫 경험 등록 시 지급하는 1 mole은 v1 정책이며, 참여 효과가 검증된 수치는 아닙니다.

## 저장과 조회

- 프로필 변경과 적립은 같은 계정 SQLite 트랜잭션에서 함께 확정됩니다. 실패하면 둘 다 저장되지 않습니다.
- 쓰기 권한은 `BEGIN IMMEDIATE` 이후 현재 세션을 검증하는 트랜잭션 진입 시점에 판단합니다. 진입 전에 만료·철회된 세션은 거절하며, 승인된 짧은 동기 저장 중 자연 만료된 세션은 해당 저장을 마칩니다. 이후 요청은 다시 권한을 검증합니다.
- 잔액은 원장 전체의 합계입니다. 화면의 최신 20개 내역을 합산해 잔액으로 사용하지 않습니다.
- 서버가 금액과 적립 사유를 결정합니다. 클라이언트가 금액·계정·이벤트를 제출하는 적립 API는 없습니다.
- `GET /api/account/mole`은 현재 로그인 세션의 계정만 읽습니다. 조회 조건을 받지 않으며, 만료·철회·방문자 요청에는 잔액을 반환하지 않습니다.
- 잔액과 내역은 같은 DB 조회 시점에서 읽고 `Cache-Control: no-store`로 응답합니다. 원장에는 경력 본문이나 Google 토큰을 저장하지 않습니다.
- 로그인 준비 중, 로딩, 오류는 실제 잔액 0과 구분해 표시합니다.

## 잘못된 적립 정정

신뢰된 운영자가 잘못 지급된 **원 적립 ID**를 확인한 경우에만 서버의 비공개 관리 터미널에서 다음 명령을 사용합니다.

```text
python -m rndplz.account_admin reverse-mole --id <원적립ID> --reason incorrect_award
```

명령은 원 적립을 수정·삭제하지 않고 연결된 -1 보정행을 한 번 추가합니다. 같은 적립을 다시 취소해도 중복 차감하지 않으며, 최초 적립 자격을 초기화하지 않습니다. 공개 정정 API나 잔액 직접 수정 기능은 제공하지 않습니다.

## 확인 범위

구현 검증은 격리된 합성 계정과 DB를 사용합니다. 실제 Google 로그인, 운영 계정에 대한 지급, 운영 DB·첨부 저장소의 재배포 후 보존은 별도 확인 대상입니다. 운영 저장소가 초기화되면 원장도 함께 영향을 받으므로 지속 보관 설정을 완료하기 전에는 운영 포인트 보존을 보장하지 않습니다.
